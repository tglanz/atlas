# atlas_ui

React, TypeScript and Vite web app.

## Commands

```
pnpm install
pnpm dev            # dev server on :5173, proxies /api to the backend on :8080
pnpm build          # type-check and bundle into dist
pnpm test
pnpm lint
pnpm format         # format the code
pnpm format:check
```
