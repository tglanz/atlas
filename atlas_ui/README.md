# atlas_ui

React, TypeScript, Vite frontend for Atlas. See `../docs/tooling.md` for versions.

## Commands

Run from this directory.

| Purpose                       | Command             |
| ----------------------------- | ------------------- |
| Install                       | `pnpm install`      |
| Dev server                    | `pnpm dev`          |
| Format                        | `pnpm format`       |
| Check formatting              | `pnpm format:check` |
| Lint                          | `pnpm lint`         |
| Build (type-check and bundle) | `pnpm build`        |
| Test                          | `pnpm test`         |
